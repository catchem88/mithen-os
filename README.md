MithenOS is a customized version of Windows, designed to be lightweight, stable, and focused on improving performance, privacy and compatibility. It aspires to re-create what Windows as an operating system should have been - easy and simple. Now compatible with [AME Wizard](https://amelabs.net)🧙.

## ✨ Key Features

- 🎯 Easy to use, just drag and drop the playbook into [AME Wizard](https://amelabs.net)
- 🗑 Removes bloatware and unnecessary system components
- ⚡ Optimizes your system for performance and improved privacy
- 🧩 Configures Windows Update with a sane deferral profile and blocks Adobe telemetry
- 🔧 Integrates the [Mithen-Tool](https://github.com/catchem88/mithen-tool) to customize your system further, including a System Monitor tab
- 📦 Optionally installs the Mithen apps: [View](https://github.com/catchem88/mithen-view), [PDF](https://github.com/catchem88/mithen-pdf), [Player](https://github.com/catchem88/mithen-player), [Zip](https://github.com/catchem88/mithen-zip)

## 💻 System Requirements

MithenOS Playbook currently supports ARM64 and AMD64 builds of the following Windows versions:

- Windows 10 21H2 `19044` (+ LTSC)
- Windows 10 22H2 `19045`
- Windows 11 23H2 `22631`
- Windows 11 24H2 `26100` (+ LTSC)
- Windows 11 25H2 `26200`

Any other build **is not** supported by Mithen.

⚠️ ISO Injection is only supported on Windows 11 ISOs.

## 🚀 Getting Started

Ready to elevate your Windows experience? Follow these simple steps:

> [!CAUTION]
> It's recommended to start with a fresh, stock Windows installation before applying the playbook to avoid potential conflicts with existing software and user data.

1. Download [AME Wizard](https://amelabs.net) and our playbook from the latest [releases](https://github.com/catchem88/mithen-os/releases).
2. Launch the AME Wizard and drag-and-drop the playbook into the interface.
3. Follow the on-screen instructions to complete the installation.
